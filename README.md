One line of office comedy, at most 200 characters, written to be judged head to head: a reply-all thread that will not die. One click to escape it, and the escape itself promotes you to admin of the very thread you were trying to leave — the office's way of rewarding initiative.

> I hit reply-all to ask to be removed from this thread, and somehow I'm now the admin of it.

## Run it

```sh
python3 main.py
```

The program self-checks the kit's gates (UTF-8, 1–200 characters, one line, not whitespace-only) and refuses to write if any gate fails, then writes the line to `/output/entry.txt` and verifies it by reading it back.
